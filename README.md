## 🚀 Acerca del Proyecto

Este Sistema de Rifas es una solución integral diseñada para organizar, gestionar y comercializar rifas de manera profesional. Construido con tecnologías web modernas, ofrece una interfaz pública atractiva para los participantes y un panel de administración robusto para gestionar boletos, pagos y estadísticas.

Desarrollado con el sello de calidad y excelencia de **Aftersoft**, garantizando rendimiento, seguridad y una experiencia de usuario excepcional.

## ✨ Características Principales

### Para el Usuario (Interfaz Pública)
- 🎫 **Exploración de Rifas:** Catálogo visual de las rifas activas con detalles, premios y costos.
- 🎯 **Selección Interactiva:** Interfaz intuitiva para seleccionar boletos disponibles de forma manual o aleatoria (máquina de la suerte).
- 📱 **Reserva Fácil:** Formulario rápido para reservar boletos e instrucciones claras de pago.
- 💬 **Integración con WhatsApp:** Generación automática de mensajes con los detalles de la compra (Monto, boletos, título de la rifa y número de folio) listos para enviar al administrador junto con el comprobante de pago.
- 🔎 **Buscador de Folios:** Herramienta para que los usuarios puedan verificar el estado de sus reservas y boletos en cualquier momento.

### Para el Administrador (Panel de Control)
- 📊 **Dashboard y Métricas:** Vista general de ingresos, boletos vendidos y rendimiento de las rifas.
- 🎟️ **Gestión de Rifas:** Crear, editar, pausar o eliminar rifas. Subida de imágenes, asignación de precios y configuración del límite numérico de boletos.
- 📝 **Control de Reservas:** Visualizar, buscar, aprobar o rechazar reservas. Al aprobar una reserva, se puede enviar automáticamente una confirmación y comprobante por WhatsApp al cliente.
- ⚙️ **Configuración Global:** Personalización dinámica del nombre del sistema, número de WhatsApp principal para contacto, instrucciones de pago (cuentas, CLABE) y enlaces de redes sociales.
- 🔐 **Gestión de Administradores:** Control de acceso y administración de múltiples cuentas de usuarios con permisos administrativos (crear, visualizar, editar y eliminar, asegurando que siempre exista al menos un usuario administrador activo).

## 🛠️ Stack Tecnológico

- **Frontend:** React 18, TypeScript, Tailwind CSS, componentes de UI modulares y Lucide Icons.
- **Backend:** Node.js con Express.js.
- **Base de Datos:** PostgreSQL para persistencia de datos relacional.
- **ORM:** Prisma Client para interactuar ágil y tipadamente con la base de datos.
- **Seguridad:** Encriptación de contraseñas con bCrypt y validación segura con JSON Web Tokens (JWT).
